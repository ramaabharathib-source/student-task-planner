# Student Task Planner

A small task-management web app designed for students. Add tasks, assign a
priority, mark work as complete, filter the task list, and delete tasks.

## Features
- Add tasks with Normal, Important, or Urgent priority
- Mark tasks as completed
- Filter all, remaining, and completed tasks
- View task counts
- Save tasks in browser localStorage

## How to run
Open `index.html` in a modern web browser. No installation or server is required.

## Note
Tasks are saved in the browser on the current device. Clearing browser data
or using another browser/device will not carry the tasks over.

## Technologies
HTML, CSS, JavaScript, and browser localStorage.
